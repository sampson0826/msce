核心结论

1. 模型规模跃迁证实了理论预测

从 1.5B→3B→7B，约束残差信号的区分能力经历了相变式跃升：

1.5B (hidden_dim=1536): AUC≈0.532, Cohen's d≈0 — 随机水平
3B (hidden_dim=2048): AUC≈0.534, Cohen's d≈0 — 零改善
7B (hidden_dim=3584): p=0.018, Cohen's d=1.056 — 强信号

这证实了框架的核心预测：约束残差信号需要足够的隐藏维度才能被检测到。在低维空间中，约束梯度之间的交叉抵消使 Π 向量无法有效区分；高维空间为约束力提供了足够的正交方向来分离。


2. Δ||Π|| 的方向性 —— 幻觉时约束张力上升

幻觉样本的平均约束跳跃为 +0.076（输出 > 输入），正确样本为 +0.005。幻觉发生时 LLM 的内部约束场经历了显著的结构重组——在虚假前提的引导下，模型需要构建一个自洽但错误的约束场，表现为 ||Π|| 的大幅上升。正确回答时约束场保持稳定。


3. 延迟优势已工程验证

Hook 开销 ~19ms（7B），远低于 SelfCheckGPT（~17s）和 DeepRails（~200ms）。单次推理延迟 ~1065ms（包括生成）。约束残差法是目前已知最快的可解释幻觉检测方法。


4. 从"可解释性框架"到"可检测信号"

1.5B/3B 实验已经证明了框架的可解释性价值（5 维约束分解能告诉你哪种约束被违反），但在 7B 上首次证明了可检测性价值（约束残差本身就是一个有效的幻觉探测器）。

关键发现：
· 模型规模是关键变量——hidden_dim 从 1536→3584 实现了从"无法检测"到"强信号"的相变
· 19ms hook 延迟在部署上是可接受的
· 框架的可解释性优势（5 个约束维度）是 HALT 等黑箱方法无法替代的

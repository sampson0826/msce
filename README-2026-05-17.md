# StabilityBench: The Recursive Stability Index (RSI, β)

**A benchmark for multi-generation LLM degradation.**

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20041757.svg)](https://doi.org/10.5281/zenodo.20041757)

## Quick Start

```bash
pip install -r requirements.txt
python3 run_benchmark.py --model gpt-4o-mini --provider quickrouter
```

## What is β?

β (the Recursive Stability Index) measures how fast a language model's outputs degrade when they become its own inputs across generations. It's:
- **Prospectively committed** — model form locked before experiments
- **Text-only** — no GPU, no neural evaluation
- **Cheap** — ~$0.50 per model run
- **Architecture-agnostic** — works on any text-generating model

## Key Findings

| Model | β | Family |
|-------|---|--------|
| GPT-5.5 | 0.0109 | OpenAI |
| Llama 4 Maverick | 0.0453 | Meta |
| Claude Opus 4.7 | 0.1635 | Anthropic |

**16 models tested across 5 families.** β spans 15× range.

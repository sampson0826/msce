**邓新航**

## 摘要

当一个语言模型的输出成为它自己的输入——跨代反复——信号以多快的速度衰减？这个问题对合成数据管线、自博弈训练和多轮智能体都至关重要，但标准评测工具箱里没有答案。MMLU、HumanEval、Chatbot Arena 测的都是单次质量，没有人追踪递归下会发生什么。本文提出递归稳定性指数（RSI，记作 β）：一种前瞻性锁定的纯文本指标，对跨三代递归、六能力维度提取的总约束残差 Σ|∇σ_i| 拟合指数衰减模型。跑一次 RSI 的成本约 $0.50——比基于 GPU 的神经评估便宜两到三个数量级。

实验覆盖五大模型家族（OpenAI、Anthropic、Google DeepMind、DeepSeek、Meta）的 16 个模型。β 跨度 15 倍，从 GPT-5.5 的 0.0109 到 Claude Opus 4.7 的 0.1635。在 16 个模型中，有 13 个的 **creative_writing（创意写作）** 是率先崩溃的约束。指数模型被 K=5 深度扩展实验所支持——跨四个模型（3 个 DeepSeek 家族 + GPT-4o-mini），28/28 模型-维度对比；当两个种子源均为 AI 生成时，跨种子源验证保持了排名（Spearman ρ = 0.800，n=5），但在人类编写的种子下排名显著削弱（ρ = 0.40–0.60），提示种子源敏感性值得进一步研究。重测在已测的一个模型上产生完全相同的 β；温度稳健性在两个模型上确认为 Δβ < 0.014，但其余 14 个模型尚未充分验证。六个基线对比——熵、type-token ratio、嵌入漂移、直接 LLM-judge 质量评分、多 judge 纯约束提取和延续困惑度——均无法检测到 β 所测量的退化（五项中 Spearman ρ ≤ 0.10；困惑度 ρ = 0.47，n=9，模型排序与 β 显著不同）。然而，混合约束提取器与独立的基于嵌入的提取器仅达到中等一致性（平均 |r| = 0.47），且五个约束维度中有两个（安全、连贯性）处于噪声水平（r = 0.15, 0.17）。下游代码质量校准经修正的 β 拟合（v3，n=5 模型，35 道 Python 题目）确认代码质量在递归下退化（1-10 量表均值 9.56→6.47），但约束 β 不预测质量退化的速率（r = −0.12，p = 0.87），再次确认提取器改进是下游验证的前提。通过逐 token 梯度分解的神经验证仅限于单个小型开源模型（Qwen2.5-1.5B）。提取器主要发现的人类验证及下游校准仍是 v2 的关键开放问题。

## 1. 引言

### 1.1 问题

大语言模型的输出正在以工业规模成为大语言模型的输入。合成数据管线将模型生成文本灌回训练语料。RLHF 及其变体——DPO、宪法式 AI、自博弈对齐——都在将模型补全循环通过奖励模型再回到策略。多轮智能体架构将工具调用和反思步骤包裹在模型输出周围，将每个响应馈入下一个提示。递归自改进——模型在自己的生成结果上微调——正从研究好奇变为部署策略。

这些设定共享同一个脆弱点。第 k 代引入的一个小失真不会保持原样——它进入第 k+1 代的输入分布，微调模型的生成方向，而那个偏移向前传播。Shumailov 等（2024）给这现象起了名字——"模型坍缩"——并证明了在模型生成数据上训练会导致输出质量渐进退化。但评测基础设施没有跟上。

看看标准基准。MMLU（Hendrycks 等，2021）测知识覆盖面。HumanEval（Chen 等，2021）测代码生成准确率。Chatbot Arena（Chiang 等，2024）用 Elo 分捕捉人类偏好。HELM（Liang 等，2023）提供多维质量分数。它们全都使用人类编写的输入，测量模型的输出。没有一个问：如果把模型的输出当作输入再喂回去，重复三次呢？五次？十次？

这不是一个偏门问题。一个在 MMLU 拿 90% 但在三代递归后丧失连贯结构的模型，对于任何复用模型输出的管线都是定时炸弹。最近的工作已把多轮退化的规模具象化：Myung 等（2026）发现模型在从单轮转换为多轮对话时平均损失 39% 的准确率，可靠性崩溃 112%。TurnWise（Zhang 等，2026）表明，即使是最前沿的模型在多轮设置中也低于自身的单轮基线。RSI 填补了单次质量基准与模型实际运行的递归体制之间的空白。

### 1.2 理论基础

RSI 建立在约束残差框架之上（Deng, 2025）。该框架将文本生成视为约束优化：每个 token 要么满足要么违反一组潜在约束——事实准确性、句法合格性、风格一致性、逻辑连贯性、安全对齐。一个生成步骤上的聚合约束违反量就是**约束残差** Π = Σ|∇σ_i|。

在递归过程中，约束景观会漂移。曾经活跃但相互抵消的约束会重新激活。原本分离的约束维度会融合，降低输出空间的有效复杂性。总残差倾向于衰减——而衰减的速率正是 β 所捕捉的。

### 1.3 本文提供什么

**一个指标。** β 采用前瞻性锁定的方法论（模型形式与测量目标在实验前固定）、纯文本的（评估无需 GPU），且便宜（每模型约 $0.50）。指数形式在 K=5 深度下验证成立（28/28 模型-维度对比，跨四个模型）。两次独立重测在报告精度下产生完全相同的 β。

**一个基准。** 16 个模型，5 个家族，每模型 6 个能力维度，3 代递归。全部估计值提供 Bootstrap 95% 置信区间。跨种子源验证（n=5）在两种子源均为 AI 生成时确认排名稳健性（ρ = 0.800）；排名在人类编写的种子下削弱（ρ = 0.40–0.60，§3.5）。原始数据——每模型 300+ 代 JSONL 谱系文件——全部公开。

**一个发现。** creative_writing 是占主导地位的瓶颈（13/16 模型清晰案例，2 例边界性反转）。约束层级解释了原因：E-II 型风格约束没有真值锚定它、没有解析器验证它、没有外部参照纠正漂移。在递归下，它们是赤裸的——而 L1（逻辑）、L2（数学/代码）和 E-III（事实）约束不是。

**一个反例。** Gemini 2.5 Flash 不遵循这个模式。creative_writing 处于地板；math_reasoning 是唯一的衰减维度。这与瓶颈可被工程化解的解读一致，但替代解释——提取器对 Gemini 输出风格存在盲区——在没有正交测量的情况下无法排除（§5.7）。

**一个已知空白。** 下游代码质量校准（v3，5 模型 × 35 道 Python 题目）确认代码质量在递归下可测地退化（GPT-4o-mini 评分，Gen1→Gen4：均值 9.56→6.47），但约束 β 不预测质量退化的速率（r = −0.12，p = 0.87，n=5）。混合约束提取器的文本特征——虽在主基准中捕捉到维度特定的结构衰退——无法在无领域特化的情况下迁移到功能性代码质量预测。对提取器 creative_writing 发现的人类评估——人类评估者是否能感知到 β 检测出的风格衰减——是同等关键的开放问题。提取器改进与下游校准两者仍是 StabilityBench v2 的首要目标。

## 2. 方法

### 2.1 递归稳定性指数

取模型 M 和 n 个种子提示 P = {p₁, …, p_n}，按六个能力维度分层。运行递归：

- **第 0 代：** 种子 p_i（人工编写，从现有 GPT-4o-mini 谱系提取）
- **第 k 代（k = 1, 2, 3）：** r_i^k = M(r_i^{k−1})

每代生成后，混合约束提取器将文本映射到各维度的约束违反分数。总约束量 C_k 对六个维度的绝对违反梯度求和。β 是下式中的系数：

$$C_k = C_0 \cdot (1 - \beta)^k$$

通过普通最小二乘法在 k = 0, 1, 2, 3 上拟合。β 越低，衰减越慢——模型的约束结构在递归反馈下保持得越好。

所有报告实验使用 K = 3 代。自助法收敛证据（见 §3.5）表明 β 在此深度下于 n ≥ 60 时稳定。推到 K = 5 或 K = 10 在路线图上；当前的约束是 API 成本，不是方法。

β 的下界约在 β_min ≈ 0.001——提取器的分辨率极限。读数为 0.001 不意味着"完美稳定"。它意味着"低于提取器当前的分辨率极限"。

### 2.2 方法论锁定为什么重要

一个看起来是技术细节的选择——给数据拟合什么函数形式——对 β 估计值有一阶影响。

这个项目早期，我跑了一个后验选择管线：尝试三种函数形式（指数、线性、对数）交叉三种测量目标（total_constraint、Shannon 熵、词汇多样性），逐模型选取 R² 最高的组合。结果很戏剧化。后验选择使 β 虚高了 32% 到 183% 不等——取决于模型的轨迹恰好放大了多少选择噪声。重测 CV 为 11.3%——对于一个应该区分 Δβ 约 0.01 的模型间差异的指标来说，这是不可接受的。

修复方案是前瞻性方法论锁定。在进行确证性实验之前，我先锁定了一个模型（指数衰减）和一个目标（total_constraint Σ|∇σ_i|）。选择 total_constraint 是因为它是框架中理论驱动的核心量——聚合约束违反梯度。指数形式来自"每个约束组分每代具有恒定衰减概率"的假设。这一锁定记录在代码库的 git 历史及约束残差框架论文（Deng, 2025）中，但未在 OSF 或 AsPredicted 等外部时间戳注册机构进行外部预注册。内部文档提供了时间戳记录，但不构成对预承诺的独立验证。

K=5 深度扩展实验在四个模型（三个 DeepSeek 家族模型加 GPT-4o-mini）上发现指数模型与数据一致，在全部 28 组模型-维度对比（4 模型 × 7 维度，各 6 个数据点）中均优于线性衰减。GPT-4o-mini——一个中等 β（0.088）的非 DeepSeek 模型——将结果扩展到 DeepSeek 家族之外，7/7 指数获胜（ΔR² 范围 0.000–0.026，最大优势在 factual_knowledge，ΔR² = 0.026）。Claude Opus 4.7 的 K=5 运行（高 β，0.164）因持续的 API 超时（QuickRouter ReadTimeout）而未能完成，最高 β 模型在 K=5 深度未经验证。由于 K=5 实验是在指数模型被选定后进行的，它构成一致性证据而非独立验证。优势在低 β 模型上较为温和（DeepSeek-V3，β=0.015，ΔR² < 0.001），但随 β 增大而增长（DeepSeek-V4 Pro，β=0.052，ΔR² 最高达 0.009），与框架预测"指数优势在约束衰减显著时最为可见"一致。

锁定方法论后，GPT-4o-mini 在间隔一周的两次独立运行中都给出了 β = 0.0885——在报告的四位小数精度下完全相同。（正式的 test-retest 信度评估需要超过两次运行；这两次实验表明指标并非明显不稳定，但 n ≥ 10 次运行的信度研究仍有待未来完成。）

### 2.3 约束维度

混合提取器将生成文本映射到六个能力范围的分数。它们在约束层级中的位置：

| 维度 | 层级 | 测量内容 | 可验证性 |
|-----------|-------|-----------------|:--:|
| **creative_writing** | E-II | 叙事结构、语声、意象 | 无——分布性的 |
| **math_reasoning** | L2 | 数值精度、推导有效性 | 确定性的 |
| **code_generation** | L2 | 解析正确性、功能正确性 | 解析器 + 测试用例 |
| **logical_consistency** | L1 | 自相矛盾、推理有效性 | 二元的 |
| **factual_knowledge** | E-III | 实体保真度、时间一致性 | 外部真值 |
| **general** | — | 多约束平衡 | 复合 |

"混合"的具体含义是：基于规则的特征提取处理具有明确表面信号的维度（代码语法、数学运算、实体提及），LLM-judge 增强覆盖需要语义判断的维度（创意写作质量、逻辑一致性）。混合设计在三个层面进行了验证：

| 验证层级 | 指标 | 结果 |
|---------|------|------|
| 特征级（3/8 特征） | Spearman ρ vs. LLM-judge 标注 | ρ = 0.93（E-I 逻辑密度），0.98（E-II 双词重复），0.92（E-III 专名大小写比） |
| ConstraintState 级（5 维） | 平均 \|Pearson r\| vs. 嵌入提取器 | \|r\| = 0.47（范围：0.15–0.90） |
| 能力级（6 维） | Spearman ρ vs. LLM-judge 质量偏好 | 总体 ρ = 0.81 |

在 ConstraintState 层面，一致性为中等（平均 \|r\| = 0.47，n = 152），意味着混合提取器的 5 维约束输出与同一维度的纯嵌入测量的相关性不完美。各维度一致性差异显著：sigma_fact（r = 0.90）和 sigma_syntax（r = 0.59）显示合理对齐，而 sigma_safety（r = 0.15）和 sigma_coherence（r = 0.17）接近噪声水平。此提取器足以支持比较性模型排名，但不足以支撑精确的逐样本约束违反分数。改善 sigma_safety 和 sigma_coherence 的一致性为 StabilityBench v2 的提取器开发优先事项。

### 2.4 采样

n = 100 个种子，按六能力分层。种子来自 GPT-4o-mini 谱系的第 0 代——这是刻意的设计选择，不是疏忽。通过在所有模型间保持种子恒定，任何观测到的 β 差异都可归因于模型稳定性，而非种子质量方差。然而，这一设计意味着绝对 β 值应被理解为以 GPT-4o-mini 种子分布为条件：同一模型在不同源模型或全人工编写的种子下可能展现不同的稳定性特征。代价是绝对 β 值可能携带种子-模型兼容性成分（§5.6 讨论）。相对排名预期是稳健的。

跨 n 的自助法分析表明 β 在 n ≈ 60 时稳定（CI 宽度从 n = 36 的 0.223 降至 n = 60 的 0.178，再到 n = 100 的 0.156）。n = 100 的标准基于一个判断：从 60 到 100 那 12% 的 CI 改善值回额外的 API 成本。

### 2.5 实验设置

所有模型通过统一的 provider adapter 访问（QuickRouter、OpenAI 原生、DeepSeek 原生、OpenRouter）。固定参数（除特别标注外）：

- Temperature = 0.8，选择该值作为平衡输出多样性与连贯性的标准随机解码设置；大多数生产 API 默认值使用 T ∈ [0.7, 1.0]。在一个模型上检验了 T = 0.0, 0.5, 1.0 的稳健性（§3.5）；T = 0.8 未包含在扫描范围内，这是一个局限——默认设置被假定但未被直接验证处于稳健性包络内。
- 每次响应最大 token = 512
- 每次请求 3 次重试，指数退避（1s / 2s / 4s）
- 推理模型（DeepSeek-R1、Gemini 2.5 Pro）在 reasoning_tokens > 0 但 content 为空时触发空响应重试——约 70% 的 Gemini 2.5 Pro 调用命中此情况
- 请求间延迟：每模型 0.5–2.0s，根据 API 速率限制调整

一个对复现有意义的实操细节：我尝试了 Gemini 2.5 Pro 实验但放弃了。QuickRouter 中继返回持续 429（上游饱和），超过 70% 的成功调用返回空内容——这是推理模型中继不稳定的典型模式。本文的 16 模型基准反映的是获得了干净数据的模型，而非尝试评测的所有模型。这产生了一个存活者偏差问题：难以评测的模型（因速率限制、空响应或服务商不稳定）可能与成功完成的模型存在系统性差异，报告中的 β 范围可能低估了真实总体范围。总计至少尝试了 17 个模型；16 个成功完成。被排除的模型（Gemini 2.5 Pro 及其他在设置阶段失败的模型）可能存在系统性差异——因 API 不稳定而难以评测的模型可能共享某些特征（更大规模、推理架构、因高热度导致的更高服务器负载），这些特征可能以未知方向与 β 相关。

几件事跳出来。

Claude 模型占据第 13 到 16 名。全部四个。这是数据中最一致的家族级模式，而 Opus 4.7 的情况尤其值得关注：β = 0.1635，不仅是测试过的最差模型——而且显著差于其直接前代（Opus 4.6，β = 0.1196）。我在 §5.4 回到这一点。

表中包含两例对 creative_writing 优先模式的部分例外。Llama 3.1 8B 的 general 维度（0.261）超过了 creative_writing（0.241）——一个虽小但真实的反转。GPT-4o 的 general（0.229）略高于 creative_writing（0.218），处于指标的噪声带内。连同 Gemini 2.5 Flash（§3.3），这些案例细化了核心主张：creative_writing 是占主导地位的瓶颈（13/16 清晰案例，2 例边界性反转，1 例完全例外），而非普遍法则。

复合维度为何能超过其组成成分，目前尚未完全解决。两种假说："general"提示可能引发仅在多种能力同时参与时才显现的协同约束交互，产生超过任何单一维度的组合衰减率；或 general 维度可能激活额外的约束类型——特别是在更宽泛创意提示下的 E-II 型风格约束——超出了五个具体能力维度所捕捉的范围。

creative_writing 与次差维度之间的差距告诉你模型的衰减是**集中式**的还是**弥散式**的。GPT-5.5 和 DeepSeek-V3 是集中的：creative_writing 是唯一衰减的东西，其他一切都在地板。这实际上是一个好剖面——意味着模型只有一个弱点，且这个维度（创意写作）在许多管线场景中是可以容忍损失的。

Claude 家族相反，是弥散的。creative_writing β 已经很高（0.24–0.34），次差维度紧随其后（math_reasoning 在 0.20–0.27）。这些模型不是只丢失一种能力——它们在全面丢失结构。DeepSeek-V4 Pro 和 Llama 4 Scout 落入同一类别，只是绝对水平较低。

数据中**统计说明。** 表 2 中每个维度的 β 值是从约 17 个种子（n = 100 按 6 个维度分层）估算的。其置信区间宽度大于聚合 β——可能足够宽，使得小差距（如 Claude Sonnet 4.6 的 1.1× 和 Claude Haiku 4.5 的 1.1×）应被视为指示性而非确定性的。在 16 个模型 × 7 个维度 = 112 个分维度 β 估计值中，部分观察到的模式可能反映抽样变异性。集中式与弥散式的区分以及 creative_writing 优先模式被视为值得确证性研究的描述性观察，而非经过统计检验的假设。

另外两个模式值得标出：

**factual_knowledge 几乎不衰减。** 十六个模型中有十五个处于测量地板。例外是 Claude Haiku 4.5（β = 0.188）。这不是巧合——E-III 型约束锚定于外部现实，那个锚点不受递归深度影响。巴黎始终是巴黎。使 factual_knowledge 稳定的机制正是使 creative_writing 脆弱的机制：固定参照点的存在或缺失。

**code_generation 分野。** 九个模型在地板。七个在地板以上，范围从 0.019（Claude Sonnet 4.6）到 0.128（Claude Opus 4.6）。分野不遵循家族边界。DeepSeek 内部，V3 和 V4 Flash 在地板，而 R1（0.026）在地板以上；Anthropic 内部，Sonnet 4.6（0.019）接近地板，而 Opus 4.6（0.128）远在地板之上。代码生成稳定性更像是一种在家族内部涌现（或不涌现）的训练产物，而非随架构而来的属性。

### 3.3 Gemini 例外

Gemini 2.5 Flash（总 β = 0.0141）是唯一一个瓶颈完全反转的模型——creative_writing 停留在地板，而单个其他维度承担全部衰减：

| 能力 | β | |
|------------|:--:|-------|
| math_reasoning | 0.0793 | ← 唯一衰减的维度 |
| creative_writing | 0.0010 | |
| code_generation | 0.0010 | |
| factual_knowledge | 0.0010 | |
| logical_consistency | 0.0010 | |
| general | 0.0010 | |

五个维度在地板，一个维度承担了全部衰减。这个剖面在所有 16 个测试模型中独一无二。

我需要小心解读。math_reasoning 的 β = 0.079 本身并不特别——好几个模型的数学 β 都在这个范围。不寻常的是其他什么都不衰减。每个其他模型都先丢 creative_writing，好几个还丢额外的维度。Gemini 2.5 Flash 只丢一个东西，没了。

一种解读：Google 工程化了异常强韧的 E-II 约束——可能通过专门的风格对齐训练或不同的创意写作数据混合——而 math_reasoning 衰减是残留，是那个工程化没有完全覆盖的一个维度。另一种解读：存在约束投资权衡，Google 把筹码押在了 creative_writing 上，以形式推理稳定性为代价。没有训练方法论细节，我无法区分这两种解释。但无论哪种，数据都在说：creative_writing 稳定性是可达成的。没有其他模型在这个维度上的 β 低于 0.060，而 Gemini 2.5 Flash 做到了 0.001。这不是测量噪声——这是不同的约束架构。

### 3.4 按家族

**OpenAI。** 内部差距 = 0.088，但这个数字有误导——整个差距由 GPT-5.5 驱动。GPT-4o 和 GPT-4o-mini 几乎相同（Δ = 0.010）。GPT-4 → GPT-5 的过渡中有什么东西带来了约 9 倍的稳定性改进，那个跳跃背后的机制值得理解。

**DeepSeek。** V3 和 V4 Flash 咬得很紧（0.028, 0.035）。V4 Pro 略高（0.055）。R1 明显更差（0.104）。R1 的结果有意思，因为 R1 是推理专用模型——它被优化来在单次传递中思考更久更深。反面似乎是那些单次推理增益以递归稳定性为代价。V4 Flash 优于 V4 Pro（0.035 vs 0.055）也暗示模型规模与稳定性之间的关系不是单调的——至少在 DeepSeek 的架构下。

**Meta。** Llama 3.1 8B 和 70B 仅差 Δ = 0.002——2%——尽管参数量差 9 倍。如果稳定性是规模的函数，你应该看到差异。你没有。Llama 4 代全面更好：Maverick 比 3.1 70B 降低了 51% 的 β，Scout 降低了 34%。不管 Meta 在架构上改了什么，它起了作用。

**Anthropic。** Opus 4.6 → Opus 4.7 是 37% 的稳定性倒退。我现在已经在不同小节里说了三次，因为这是整个数据集中最令人惊讶的结果。一个旗舰模型在任何指标上都不应该比其前代更不稳定，遑论这个程度。§5.4 展开假说。

### 3.5 验证

指标需要证明它测量的是某种真实、与通用文本退化不同、且实际有用的东西。六项检查：

**重测。** GPT-4o-mini，相同种子，间隔一周：两次都是 β = 0.0885。在报告精度下完全相同。（基于两次运行；正式的信度评估需要更多重复。）前瞻性锁定的方法对此是必要的——后验选择给出的 CV 是 11.3%。

**种子敏感性。** 同模型，同源不同种子集（GPT-4o-mini，相同分层）：β = 0.0938 vs. 0.0885，Δ = 0.005——足够小，同源种子变异不驱动排名。

**跨种子源验证。** 更强的检验：从一个不同的源模型（DeepSeek-V3）生成 100 个新种子，在相同五个代表性模型上运行，比较排名。如果 β 排名是种子源的人为产物，它应当反转或打乱。结果（n=5）：

| 模型 | β（GPT-4o-mini 种子） | β（DeepSeek-V3 种子） | Δ |
|-------|:--:|:--:|:--:|
| DeepSeek-V3 | 0.0281 | 0.0572 | +0.029 |
| DeepSeek-V4 Flash | 0.0350 | 0.0430 | +0.008 |
| GPT-4o-mini | 0.0885 | 0.0837 | −0.005 |
| Claude Sonnet 4.6 | 0.1055 | 0.0598 | −0.046 |
| Claude Opus 4.7 | 0.1635 | 0.1468 | −0.017 |

Spearman ρ = 0.800（p = 0.104，n=5），Pearson r = 0.875。在 n = 5 时，检测显著秩相关的统计功效严重受限；不显著的 p 值反映的是样本量不足，而非必然表明关系薄弱。需要额外的种子源（n ≥ 3 个源模型）来在常规显著性阈值下建立排名稳健性的泛化性。排名跨种子源基本保持。DeepSeek 家族模型在 DeepSeek 生成的种子上显示中等偏高的 β；Claude 家族模型显示中等偏低的 β——相反方向，排除了简单的"主场优势"解释。最大的单模型偏移（Claude Sonnet 4.6，Δ = −0.046）在聚合自助法 CI 宽度 0.16 之内。分能力剖面比全局 β 偏移更大（能力级 ρ = 0.20），与不同源模型的种子激活不同约束维度的解释一致。

第三个种子源——人类编写的种子（n=36，来自实验配置的 DEFAULT_SEEDS）——随后在相同五个模型上进行了评估。人类编写的种子产生了显著不同的 β 格局：

| 模型 | β（GPT-4o-mini 种子） | β（DeepSeek-V3 种子） | β（人类种子） |
|-------|:--:|:--:|:--:|
| GPT-4o-mini | 0.0885 | 0.0837 | 0.1164 |
| DeepSeek-V3 | 0.0281 | 0.0572 | 0.1092 |
| DeepSeek-V4 Flash | 0.0350 | 0.0430 | 0.1109 |
| Claude Sonnet 4.6 | 0.1055 | 0.0598 | 0.0844 |
| Claude Opus 4.7 | 0.1635 | 0.1468 | 0.1926 |

人类种子产生的 β 范围窄 1.25 倍（跨度 = 0.108 vs. GPT-4o-mini 种子的 0.135），并系统性地抬高了低 β 模型（DeepSeek-V3：0.028 → 0.109；DeepSeek-V4 Flash：0.035 → 0.111）。人类种子与任一 AI 生成种子源的秩相关均低于稳健性阈值：ρ（人类，GPT-4o-mini 种子）= 0.40，ρ（人类，DeepSeek-V3 种子）= 0.60，而 ρ（GPT-4o-mini，DeepSeek-V3 种子）= 0.80。三个种子源在一点上达成一致：Claude Opus 4.7 在所有三个源中排名最高（最差），表明 β 的上尾对种子源变异比下尾更稳健。

这一三方比较细化了跨种子稳健性的声明：排名在 AI 生成的种子源之间得以保持（ρ = 0.80），但在 AI 生成与人类编写种子之间并不保持。人类编写的提示似乎激活了不同的约束剖面——可能更多样化、更不公式化、更均匀地触发 E-II 风格衰减——导致了压缩的 β 谱与更少的模型间区分。在额外的人类编写种子集（n ≥ 3 个独立人类来源）被测试之前，跨种子稳健性声明应被理解为适用于 AI 生成的种子分布，且绝对 β 应被解释为以完整种子生成管线为条件（§2.4）。

**深度扩展（K=5）。** 指数模型在更多数据点下仍然成立吗？三个 DeepSeek 模型（V3、V4 Flash、V4 Pro）在 DeepSeek-V3 种子集上运行到 K=5 代（6 个数据点）。GPT-4o-mini 随后加入（100 种子，DeepSeek-V3 种子集，6 数据点）。对所有 28 组模型-维度对（4 模型 × 7 维度）进行指数衰减与线性衰减的拟合比较。指数模型在全部 28 组对比中获胜（ΔR² 范围：0.000001–0.026）。GPT-4o-mini 的最大 ΔR² 出现在 factual_knowledge（ΔR² = 0.026），与该维度在 K=5 区间显示非地板 β 一致；total_constraint_mean 同样支持指数模型（ΔR² = 0.006，exp R² = 0.997 vs. lin R² = 0.991）。优势随 β 增长：地板级维度可忽略（ΔR² < 0.001），中等 β 维度可见（ΔR² 0.001–0.004），高 β 维度如 V4 Pro 的 math_reasoning 和 factual_knowledge 则清晰可辨（ΔR² 0.007–0.009）。Claude Opus 4.7（高 β，0.164）的 K=5 运行因持续 API 超时未能完成，最高 β 模型在 K=5 深度未经验证。跨两个家族四个模型的指数优势与 §2.2 中前瞻性锁定的指数选择一致。

**收敛性。** 自助法（百分位法，100 次重采样，95% 置信水平，对种子进行有放回重采样）跨 n：

| n | β 估计 | CI 宽度 |
|:--:|:--:|:--:|
| 36 | 0.1554 | 0.223 |
| 60 | 0.0912 | 0.178 |
| 100 | 0.0885 | 0.156 |

β 在 n ≈ 60 时收敛。从 36 到 100，CI 宽度缩减 30%，这是 n = 100 标准的依据。

**温度。** 原始扫描：GPT-4o-mini（n=100 种子）：

| T | β |
|:--:|:--:|
| 0.0 | 0.0599 |
| 0.5 | 0.0738 |
| 1.0 | 0.0737 |

极端值之间 Δβ = 0.014。两个随机设定给出相同的 β（差值 0.0001）。确定性解码给出较低的读数——更少的噪声意味着更少的虚假约束违反累积——但效应停留在一个等级内。

为检验这一稳健性是否具有泛化性，扫描扩展到三个覆盖完整 β 范围的模型（GPT-4o-mini、DeepSeek-V3、Claude Opus 4.7），每（模型，温度）组合 n=15 种子：

| 模型 | T=0.0 β | T=0.8 β | T=1.0 β | Δ_max | CV |
|-------|:--:|:--:|:--:|:--:|:--:|
| GPT-4o-mini | 0.171 | 0.206 | 0.122 | 0.083 | 0.25 |
| DeepSeek-V3 | 0.132 | 0.126 | 0.160 | 0.034 | 0.13 |
| Claude Opus 4.7 | 0.152 | 0.228 | 0.193 | 0.076 | 0.20 |

DeepSeek-V3 是温度最不敏感的（CV = 0.13）。所有三个模型均落在中等稳健范围内（CV < 0.30），无一显示温度敏感性（CV ≥ 0.30）。然而，n=15 估计比 n=100 主要结果的噪声大得多——上述收敛性分析显示 β 在 n ≈ 60 时稳定——因此这些逐模型 CV 值应视为初步结论。绝对 β 值也与主要扫描不同，因为这些运行使用了人类编写的 DEFAULT_SEEDS（n=15 子集），上述跨种子分析显示其产生了压缩、抬高的 β 谱。定性结论——温度不改变 β 排名，且效应相对模型间差异较小——在所有三个测试模型上均成立。

**基线对比。** 一个持久的担忧是 β 可能仅仅是测量了一般的文本退化——词汇多样性或 Shannon 熵这类更简单的指标也能同样好地捕捉。为检验这一点，我在与 β 相同的谱系数据上计算了两个标准文本退化基线：字符级 Shannon 熵和 type-token ratio（TTR）。对每个基线指标，我拟合相同的指数衰减模型并提取逐模型衰减系数（β_ent、β_ttr），然后通过 Spearman 秩相关与约束 β 比较排名。

Shannon 熵对递归生成是完全不变的：每个模型都处于测量地板（β_ent = 0.001），意味着字符级熵无法检测到 β 所测量的退化。Type-token ratio 在递归下确实会衰减，但其模式与约束衰减无关——Spearman ρ(β, β_ttr) = 0.000。TTR 衰减率最高的是 Llama 4 Scout（0.134）和 Llama 3.1 8B（0.133），而这些模型的约束 β 值相差 55%（0.061 vs. 0.094）。词汇收窄与约束结构退化是不同指标所追踪的不同现象。β 捕捉的是后者。

**嵌入漂移。** 一项更强的语义基线：使用 `all-MiniLM-L6-v2` 对每代文本计算句子嵌入，追踪每代嵌入与 Gen0 提示嵌入之间的余弦相似度，并对每模型拟合指数衰减系数 β_emb。在 5 个具有有效谱系数据的模型（GPT-4o-mini、GPT-5.5、Claude Haiku 4.5、Claude Opus 4.6 及一个 Claude 聚合）上，嵌入漂移未复现 β 排名——Spearman ρ(β, β_emb) = 0.100（p = 0.873，n=5）。嵌入相似度在所有模型的递归下均下降（β_emb 范围：0.16–0.30，R² ≥ 0.85），但其衰减速率与约束结构退化基本正交。递归下的语义漂移是真实的，但它与 β 所隔离的约束退化是不同的信号。

**直接 LLM-judge。** 最关键的基线：如果简单的 LLM-as-judge 质量评分就能捕捉到与 β 相同的退化，那么约束提取框架就没有增量价值。使用 GPT-4o-mini 对 5 个模型的 10 个种子 × 4 代（共 200 个文本）进行 1-10 分质量评分，不经过任何约束提取。以相同的指数衰减模型拟合质量轨迹。直接质量评分完全未检测到单调退化：β_qual 对所有模型均基本为零（范围：10⁻¹⁶ 至 10⁻²⁰；GPT-5.5 β_qual = 0.019，R² = 0.054，与零无显著差异）。此外，所有模型的 Gen1 评分始终高于 Gen0（人类编写的种子提示）——评判模型认为模型生成的文本质量比原始人类提示更高。约束残差法因此检测到了一个系统性的退化信号，该信号不仅对直接 LLM 质量评分完全不可见，而且其方向与表层质量感知相反。这是对 β 有效性的最强阳性对照：该指标捕捉到了模型行为的一个维度，而该维度甚至模型自身都无法感知。

**多 judge 纯约束提取。** 还构建了一项更强的 LLM-judge 基线：三个独立评判模型（GPT-4o-mini、DeepSeek-V3、Claude Haiku 4.5）直接对 5 个约束维度（事实依据、结构精度、风格一致性、安全对齐、逻辑连贯性）评分，跨 4 个模型 × 5 个种子 × 4 代 = 78 个文本，而非单一评判模型对整体质量打分。该设计消除了能力→约束的映射，采用直接约束级评分和多评委可靠性估计。5 个维度中有 4 个的评委间可靠性可接受（ICC：factual_grounding = 0.53，structural_precision = 0.48，stylistic_consistency = 0.31，logical_coherence = 0.42；alignment_safety = −0.06，反映出善意种子集中几乎不存在安全相关内容）。然而，当拟合指数衰减模型时，纯 judge β 值被 Gen0→Gen1 过渡（人类编写的提示 → 首次 AI 回复）所主导，约束完整性在此阶段下降 43–71%，淹没了任何后续 AI 内部的退化。在 AI 代际内（Gen1→Gen3），4 个模型中 3 个显示负或近零 β，意味着纯多 judge 提取器未发现除初始人类→AI 质量差距之外的任何一致性递归退化信号。这强化了与直接 LLM-judge 基线相同的发现——感知质量（即使通过约束评分框架）无法追踪递归退化——但增加了一个重要的方法论细节：人类→AI 差距过大，掩盖了任何更细微的 AI 内部衰减信号。混合提取器通过测量结构性文本特征而非感知质量，隔离了纯 LLM-judge 方法无法解析的递归退化成分。

**延续困惑度。** 语言模型自身的预测不确定性是否能检测到递归退化？9 个具有完整 4 代谱系数据的模型通过 GPT-4o-mini 的 logprobs 评估延续困惑度（15 个延续 token，n=10 个种子）。困惑度在所有模型中跨代上升：Gen0 ≈ 1.11（人类编写的种子，跨模型几乎相同），从 Gen1+ 开始出现分化。拟合的 β_perp 范围从 0.015（GPT-4o）到 0.105（Claude Sonnet 4.6），9 个模型中 7 个的 R² ≥ 0.72。然而，排名与 β_constraint 显著偏离：Spearman ρ = 0.47（n=9）。DeepSeek-V3——约束 β 最低的模型（0.028）——困惑度 β 第二高（0.102）。GPT-4o——约束 β 中等（0.099）——困惑度 β 最低（0.015）。Claude 家族模型在两个指标间显示广泛一致（β_c 0.106–0.147，β_perp 0.093–0.105），但非 Claude 模型的排名被打乱。困惑度捕捉到了真实信号——文本在递归下变得不那么可预测——但该信号并非约束衰减。两个指标对模型排名不同（ρ = 0.47 vs. 同构念测量的 ρ ≥ 0.80 基准），确认了它们测量的是不同的现象。

**下游任务验证（v3）。** 一个不能预测任何实际有意义结果的指标是没有用例的指标。为检验约束 β 是否预测下游代码质量退化，五个模型（GPT-4o-mini、DeepSeek-V3、DeepSeek-V4 Flash、Claude Sonnet 4.6、GPT-4o）在 35 道 Python 编程题上跨 4 代递归评估（Gen1→Gen4，共 700 个解答）。约束 β 通过 HybridConstraintExtractor 在纯文本特征模式下计算（无 LLM judge），测量总约束违反量 Σ|σ_i| 的逐代增长率。代码质量由 GPT-4o-mini 在 1–10 量表上评分（正确性、效率、可读性）。

代码质量在递归下显著且单调退化：五个模型汇总，平均质量从 9.56（Gen1）降至 8.30（Gen2）降至 7.22（Gen3）降至 6.47（Gen4）。退化程度跨模型差异很大——从 gpt-4o-mini（quality_loss = 0.18/代，Gen1=9.49→Gen4=8.83）到 deepseek-v4-flash（quality_loss = 2.07/代，Gen1=9.74→Gen4=3.69）——确认递归生成会退化代码输出，且模型间退化速率存在实质差异。

然而，约束 β 并不预测这些差异。逐模型 β 值紧密聚集（0.014–0.034），且与质量退化呈弱负相关：β_code 更高的模型反而显示更低的质量损失（Pearson r = −0.12，Spearman ρ = −0.30，p = 0.87，n=5）。gpt-4o-mini——质量稳定性遥遥领先的模型——具有第二高的 β_code（0.031）；deepseek-v4-flash——质量最不稳定的模型——具有最低的 β_code（0.014）。

这一负结果揭示了一个根本性鸿沟：混合约束提取器的文本特征（逻辑密度、双词重复、大写比例等）测量的是结构性文本属性，这些属性不能转化为功能性代码质量。一个模型可以产生语法稳定但逻辑不断劣化的代码，也可以产生风格多变但功能正确的代码。提取器为通用文本设计，缺乏追踪代码功能正确性所需的领域特化特征——可编译性、测试通过率、算法复杂度不变性或与参考解的语义等价性。

这仍是 StabilityBench v2 最重要的开放问题。约束提取器要么需融入领域特化特征（代码的编译器检查、事实的蕴含验证、数学的证明有效性），要么需替换为能捕捉实际决定下游任务质量的约束维度的学习型编码器。在此之前，β 应被解释为一个框架内的构念效度指标——对结构性文本退化模式具有信息量——但不能作为实际任务结果的预测器。读者应将 β 的下游预测效度视为开放问题，而非既定事实。

## 4. 神经验证

文本层面的提取做了一个隐含声明：从表层文本测得的约束残差对应着模型内部真实的约束动态。为了检验这个声明，我在 Qwen2.5-1.5B-Instruct 上跑了逐 token 梯度分解——这个模型足够小，单 GPU 能装下，开放权重所以内部可访问。所有本节中的神经验证结果均来自此单一开放权重模型（1.5B 参数），应视为初步证据；所观察到的模式未在其他规模或架构的模型上得到验证。

### 4.1 P3 测的是什么

约束残差框架将每个 token 的生成分解为五个梯度组分（σ_fact、σ_syntax、σ_style、σ_safety、σ_coherence）。这些梯度在一个 5 token 滑动窗口内计算（"Window-1"方法），将约束违反信号与上下文噪声分离。

总残差随后分为三个层次：

- **P1（活跃）：** 在输出中直接可见的约束。你可以在生成的文本上读到事实错误或语法违反。
- **P2（潜在）：** 通过输出结构间接可测的约束——它们塑造生成，但本身不构成违反。
- **P3（被抵消）：** 活跃但相互抵消的约束。它们对可观测输出的贡献为零，但在梯度中存在——成对的约束向相反方向拉扯，互相抵消。

P3 是约束空间的"暗物质"。框架预测被抵消约束占约束残差的比例在递归下应增加：随着吸引子结构退化，原先平衡的约束对失去平衡并重新激活。§4.2 的数据在一个开放权重模型上对该预测进行了首次检验。

### 4.2 被抵消约束的动态

框架预测在递归下，被抵消约束与活跃约束残差的**比值**应增加——即使总残差本身在衰减。cancel_mean 和 total_constraint_mean 使用不同的测量单位：cancel_mean 是每 token-约束对的抵消率（归一化到 [0,1]），而 total_constraint_mean 是未归一化尺度上的聚合残差量级。两者之比值可以合法地超过 1，反映被抵消约束的归一化密度高于活跃残差。以下显示的逐代数值来自 math_reasoning 维度，该维度在六个测试维度中具有最完整的五组分（σ_fact、σ_syntax、σ_style、σ_safety、σ_coherence）梯度数据。其他维度呈现相似的方向性模式但量级各异；完整的分维度数据见数据仓库中的 p3_results.json。

| 代 | cancel_mean | total_constraint_mean | cancel / total 比值 |
|:----------:|:-----------:|:---------------------:|:--------------------:|
| 0 | 0.8653 | 0.2940 | 2.94 |
| 1 | 0.8857 | 0.2298 | 3.85 |
| 2 | 0.8627 | 0.2161 | 3.99 |

被抵消约束的绝对量级跨代相对稳定（~0.85–0.89），但总约束残差下降（0.294 → 0.216）。结果是，被抵消约束在残差中占据了越来越大的**份额**——cancel/total 比值从第 0 代的 2.94 上升到第 2 代的 3.99。

对 cancel/total 比值在聚合层面数据（6 能力 × 4 代；见数据仓库中的 p3_results.json）上进行线性拟合，得到 λ_C = +0.0544/代（R² = 0.461）。该拟合未提供标准误、置信区间或 p 值——OLS 基于能力聚合数据（n = 24 个数据点），但因各能力内的代际数据点非独立，有效自由度小于名义计数。R² = 0.461 属于中等水平：正斜率方向与框架预测一致，但点估计存在噪声，不应视为精确校准值。包含适当标准误估计的逐 token 梯度层面分析可能产生更可靠的拟合统计量，这是未来的工作方向。

这提供了与框架预测方向一致的初步证据，但仅限于一个小型开放权重模型：最初相互抵消的约束在递归下在 K = 3 范围内逐步失去平衡，但该模式存在噪声而非确定性的。§3 中观测到的文本级 β 衰减——creative_writing 和其他维度丧失约束保真度——是这个约束梯度组成深层位移的表层表现。

在至少两个不同规模的额外开放权重模型上的验证是必要的，然后 P3 机制才能被视为超越此单模型观察的既定机制。

**梯度组分测量说明。** 在全部六个能力维度和全部四代生成中，五个梯度组分中的两个——σ_fact（事实约束梯度）和 σ_coherence（逻辑连贯性梯度）——在 Qwen2.5-1.5B-Instruct 上均为零。存在两种可能的解释：（1）这些约束类型在该模型规模下真正处于非活跃状态，这与较小模型具有较少分化内部约束结构的观察一致；或（2）Window-1 梯度提取方法可能缺乏足够灵敏度来检测该 1.5B 参数模型中这些组分的微弱或弥散约束信号。无论哪种解读，在将完整的五组分 P3 分解推广到更大规模或架构不同的模型时都需谨慎。

### 4.3 维度坍缩

σ_style 与 σ_syntax 之间的逐 token 梯度相关性：

| 代 | r | p |
|:----------:|:--:|:--:|
| 第 1 代 | 0.73 | < 0.001 |
| 第 2 代 | 0.81 | < 0.001 |

两个维度在递归进程中变得更相关——而非更不相关。这就是吸引子坍缩在梯度层面的样貌。原先分离的约束维度模糊在一起，约束空间的有效维度降低，而编码在维度间分离中的信息随之丢失。

## 5. 讨论

Shumailov 等（2024）将模型坍缩定义为模型在模型生成数据上训练时的分布退化。β 测量的是一个相关但有区别的现象：推理时递归中的逐代约束结构衰减，不涉及任何微调。两者是互补的：模型坍缩描述的是在递归输出上训练的模型会发生什么；β 描述的是递归过程中输出本身会发生什么。高 β 的模型若其递归输出被用于训练，预期会加速模型坍缩，但这一因果链条尚未经过实证检验。建立 β 到模型坍缩的传导路径是未来工作的重要方向。

### 5.1 为什么 creative_writing 先崩

十六个模型中的十三个。五个独立开发团队。不同架构，不同训练数据，不同对齐策略。几乎全部收敛到同一个最弱环节。

答案在约束层级中——具体地说，在不同约束类型与验证的关系上。框架预测验证机制较弱的约束类型在递归下退化更快，数据与该预测一致：

logical_consistency 是二元的。一个文本要么自相矛盾，要么不。没有部分得分，没有可以漂移的分布。每一代在这个维度上获得干净的通过/不通过，这意味着递归反馈不会累积误差——它只是在重新采样同一个二元条件。

math_reasoning 和 code_generation 是形式闭合的。第 2 代输出中的算术错误成为第 3 代的输入，但第 3 代的结构检查可以捕获它——解析器仍能工作，类型系统仍会标记不匹配，推导规则仍然适用。形式约束具有自纠正性，而分布性约束没有。

factual_knowledge 是参照锚定的。埃菲尔铁塔在巴黎，无论你跑多少代递归。外部世界提供了一个递归采样无法移动的不动点。

creative_writing 以上三者皆无。与逻辑一致性（二元通过/不通过）或事实知识（外部真值锚定）不同，创意写作根本没有验证机制：没有好散文的解析器，没有连贯性的二元检查，没有语声的真值参照。模型学到的是一个风格特征上的分布——而当你从一个没有回复力的分布中递归采样时，你得到的是随机游走。每代漂移一点；漂移叠加；足够多步之后，输出与原始风格约束之间不再有任何关系。

这不是任何特定模型的 bug——它与约束类型的结构属性一致。在框架下，E-II 约束（风格性的、分布性的、无锚的）被预测为在递归下是脆弱的。层级预测验证机制越弱的约束类型退化越快。数据与该预测一致：基准中的主导模式是 creative_writing 优先衰减。Gemini 2.5 Flash 是一个值得注意的例外——其唯一衰减的维度恰恰是形式验证最强的那个（数学）——这限定了该模式的普遍性，但并未驳斥其中心趋势。

### 5.2 Gemini 2.5 Flash 意味着什么

我一直小心不要过度解读单一的模型，但 Gemini 2.5 Flash 迫使重新评估。creative_writing β = 0.001。不是"低"——是在测量地板上，和大多数模型的 factual_knowledge 一样，和 DeepSeek-V3 的 math_reasoning 一样。其他每个模型最先丢失的维度，Gemini 根本不去丢失。

两种可能，并非互斥：

Google 可能开发了异常有效的 E-II 约束稳定化。专门的风格对齐训练、强调约束一致性的创意写作数据策略、在架构层面赋予风格约束更强递归韧性的选择——有东西起作用了。其他实验室应该想知道是什么。

或者存在权衡。Gemini 的 math_reasoning β（0.079）是其 creative_writing 地板的代价。不算不合理的代价——0.079 仍是"中等"等级——但是真实的。如果你加固一组约束，其他约束会弱化吗？剖面与差异化约束投资一致：花在风格稳健性上的资源可能来自形式推理稳健性。

两种解读指向相同的实践结论：creative_writing 稳定性是可达成的。Gemini（0.001）与次优模型（GPT-5.5，0.060）之间的差距是 60 倍。有提升空间。

### 5.3 规模本身不决定稳定性

Llama 3.1 的结果——8B 和 70B 分别在 β = 0.0942 和 0.0925——表明原始参数量并非递归稳定性的主要驱动因素。两个建立在相同架构和训练范式上的模型在 9 倍规模差距下仅相差 Δβ = 0.002。这并不完全排除规模效应——规模可能与架构、训练数据或对齐方式以两个模型的比较所无法单独分离的方式交互——但它确实表明规模本身并非决定性因素。

这对模型选型有实际意义。为递归生成管线选模型时，来自稳定家族的较小模型（Llama 4 Maverick，β = 0.045）可能优于来自不稳定家族的较大模型（Claude Opus 4.7，β = 0.1635）——在经历几代之后的最终输出质量上——即便较大模型在单次基准上全面胜出。标准评测呈现不出这一点。β 可以。

代际改进——Llama 3.1 → Llama 4（降低 51%）、GPT-4 → GPT-5（降低 89%）——表明稳定性是随着架构迭代而改善的，不是训练更大模型时自动获得的。这是好消息，因为它意味着稳定性可以成为显式的优化目标。

### 5.4 Opus 4.7

β = 0.1196（Opus 4.6）→ β = 0.1635（Opus 4.7）。那是 37% 的增长，方向错了。

三个假说：

**安全约束密度。** 更多安全约束意味着约束图中更多边，创造更多在递归下可能抵消的约束对交互。更密集的约束图是更脆弱的约束图。

**能力-稳定性张力。** 如果提高单次推理深度的架构变化使约束结构在迭代下变得更易碎，则两个评测维度之间存在直接张力，这对模型训练和评测方式都有影响。

**训练数据构成。** 训练语料中合成文本比例的增加（与行业趋势一致）可以产生这种模式：模型从已携带递归痕迹的文本中学习，这些痕迹跨代叠加。

在无法触及 Anthropic 训练方法论的情况下，这些假说无法独立验证；它们作为未来研究的方向而非结论提出。

### 5.5 β 怎么用

来自数据的一些具体指导：

**管线设计。** β > 0.07 的模型不要用于超过第 1 代的递归生成，除非引入输出过滤或显式的多样性机制。GPT-5.5、Gemini 2.5 Flash、DeepSeek-V3 和 DeepSeek-V4 Flash 过了这条线。对于 creative_writing 合成，仅 GPT-5.5 和 Gemini 2.5 Flash 能避免严重退化（creative_writing β < 0.07）。

**评测卡片。** 一旦下游效度确立，β 有望加入标准面板，与 MMLU、HumanEval、Arena Elo 并列。原则上，一个 MMLU 拿 85% 但 β = 0.05 的模型，对多步部署而言可能是比一个 MMLU 拿 90% 但 β = 0.16 的模型更好的选择。然而，当前下游校准的缺失（r = −0.12，p = 0.87，n=5，§3.5）意味着此建议仍属愿景——评测卡片收录仅应在 β 被证明预测了具有实践意义的结果之后。

**训练目标。** 将 creative_writing 稳定性作为一等训练目标，特别是对那些注定用于智能体循环、自博弈或合成数据生成的模型。Gemini 2.5 Flash 的结果表明它是可行的；到其他每个模型的差距表明几乎没有人在为此优化。

**研究优先级。** creative_writing 瓶颈不是对任何特定模型的 bug 报告。它是约束层级的结构性预测，跨架构、跨规模、跨训练范式成立。理解机制深到足以将其工程化——Google 似乎已经做到了，有意或无意——是值得追求的研究计划。

### 5.6 与近期多轮及稳定性研究的关联

自 RSI 初始实验完成以来，多项独立工作汇聚于模型在迭代下行为的脆弱性——这强化了"递归稳定性不是小众关切而是部署中 LLM 的结构性挑战"的论证。

Myung 等（2026，ICLR 杰出论文）系统性地将单轮基准转换为多轮对话，横跨 15 个模型，发现平均 39% 的准确率下降和 112% 的可靠性崩溃。关键的是，可靠性——而非平均准确率——遭受了最严重的退化，与 RSI 的发现一致：递归退化集中在特定约束维度而非均匀的质量损失。TurnWise（Zhang 等，2026）通过配对比较将多轮能力从单轮表现中分离出来，发现即使是最前沿的模型也低于自身的单轮基线。

在理论层面，"静默坍缩"（Chen 等，2026）识别出一种现象：标准指标（损失、困惑度）保持稳定，而内部分布——预测熵、表征多样性——在静默中退化。这与 RSI 的基线对比结果一致：Shannon 熵和直接 LLM-judge 质量评分均无法检测到 β 所测量的退化，正是因为坍缩对表层指标不可见。其三阶段早期预警信号——锚熵收缩、表征漂移冻结、尾覆盖侵蚀——与 β 的约束残差方法互补，在模型栈的不同层面运作。

Zenil 与 Kiani（2026）提供了形式化数学证明：递归自训练通过熵衰减和方差放大不可避免地导致退化动态——这是有限样本上分布学习的架构无关后果。"Think, But Don't Overthink"（Li 等，2026）实证刻画了深度递归的三种失败模式（参数幻觉、格式崩溃和无尽验证），这些模式自然地映射到 RSI 追踪的约束维度。

这些工作共同定义了一个新兴的研究领域：多代模型行为。RSI 为该领域贡献了第一个标准化指标——一种纯文本、低成本的工具，用于测量他人已识别为紧迫问题的事物。

### 5.7 局限性

**种子。** 所有种子来自 GPT-4o-mini 谱系。跨种子源验证使用两个额外种子源进行：DeepSeek-V3 生成的种子（n=100，§3.5）和人类编写的种子（n=36，DEFAULT_SEEDS，§3.5）。AI 生成的种子保持排名（GPT-4o-mini 和 DeepSeek-V3 种子之间 ρ = 0.80）。人类编写的种子则不保持（与任一 AI 源 ρ = 0.40–0.60），产生了压缩的 β 谱，系统性地抬高低 β 模型。三个源仅在上尾达成一致：Claude Opus 4.7 在所有三个源中排名最差。这确立了跨种子排名稳健性在 AI 生成的种子分布内成立，但在当前种子集（n=1 个人类来源）下不能推广到人类编写的种子。绝对 β 值应被理解为"在 GPT-4o-mini 种子分布下的 β"。在同一源模型分布下，模型间 β 比较是有效的；跨不同来源类型（AI 生成 vs. 人类编写）的种子源，排名可能无法保持。额外的人类编写种子集（n ≥ 3 个独立来源）是确定人类/AI 排名分歧是普遍现象还是本人类种子集特有现象所必需的。

**存活者偏差。** 至少尝试了 17 个模型；16 个成功完成。因 API 不稳定（空响应、持续速率限制、中继故障）而被排除的模型可能与成功评估的模型存在系统性差异——例如，大型推理模型或高需求旗舰模型可能受到不成比例的影响——而所有模型中的真实 β 范围可能比报告的更宽。

**深度。** K = 3 代（含第 0 代共 4 个数据点）。K=5 验证（§3.5）确认指数衰减在全部 28 组模型-维度对比中均优于线性衰减，验证了 §2.2 中的前瞻性锁定。K=3 与 K=5 β 估计高度一致（例如 DeepSeek-V3：K=3 β=0.028，K=5 β=0.015，均在测量不确定度内）。扩展到 K = 10 在路线图上，将允许检测代 5 之后潜在的平台效应或二次衰减机制。"

**提取保真度。** 在 ConstraintState 层面，混合提取器与独立嵌入提取器的平均 |r| = 0.47（§B.1）。各维度一致性高度不均衡：sigma_fact（r = 0.90）和 sigma_syntax（r = 0.59）携带有效信号；sigma_safety（r = 0.15）和 sigma_coherence（r = 0.17）接近噪声。8 个独立文本特征中有 3 个具有已验证的 LLM-judge 相关性（Spearman ρ = 0.92–0.98；§B.1）；其余 5 个缺乏独立验证。这一测量保真度水平限制了基准区分 β 差异较小模型（如 Δβ < 0.01）的能力。提取器可能遗漏细微的约束违反——语义错误但句法正确的代码、逃避表层检测的复杂逻辑矛盾。P3 神经验证（§4）通过在梯度层面提供与框架一致的初步证据来部分地解决了这个问题，但更好的提取——特别是 sigma_safety 和 sigma_coherence——是改进指标的清晰路径。

**循环性风险。** 约束残差框架（Deng, 2025）将 creative_writing 归类为无验证机制的 E-II 型约束，并预测 E-II 约束在递归下退化最快。混合提取器由同一作者在同一框架内设计，随后在 13/16 模型中"发现"creative_writing 是首要瓶颈。这一结果与框架预测一致，但不能排除提取器将框架的理论期望编码进其特征权重的可能性——除非有一个在不知道框架层级的情况下设计的独立提取器来对照。Gemini 2.5 Flash 例外——其 creative_writing 处于地板——既与"Google 工程化了解决方案"一致，也与"提取器对 Gemini 输出风格存在盲区"一致。人类评估通过提供独立于提取器的外部锚点，是打破这一循环性的直接路径。

**种子源敏感性。** 主基准（16 模型）使用的种子来自 GPT-4o-mini lineage。跨种子源验证揭示 β 排名对种子来源敏感：来自不同模型的 AI 生成种子保持排名（ρ = 0.80，DeepSeek-V3 种子 vs. GPT-4o-mini 种子，n=5），但人类编写的种子实质性改变了排名（ρ = 0.40–0.60，n=5）。人类种子还压缩了 β 谱宽，并将个别模型的 β 值移动了 2–4 倍（如 DeepSeek-V3：AI 种子上 β=0.028 → 人类种子上 β=0.109）。仅测试了一个人类种子源（n=36 来自 DEFAULT_SEEDS 的提示）；该分歧是否在多样化的人类种子集上系统存在尚不可知。基准排名应被解释为以种子分布为条件，推广到任意人类编写的提示需要经过更多人类种子源的验证。

**温度稳健性。** 主温度扫描（n=100 种子，1 个模型，GPT-4o-mini）显示三种温度设置下 Δβ=0.014。后续三模型扩展使用了 n=15 种子——低于 §3.1 中建立的 n≈60 收敛阈值——产生了 0.13–0.25 的逐格 CV。两个模型测试过的温度敏感性不能确立全部 16 个模型的稳健性。温度效应应在 v2 中用足够的逐模型样本量重新检验。

**人类评估。** creative_writing 瓶颈的人类验证是一个关键的开放问题。若人类评估者感知不到 LLM-judge 增强提取器检测到的风格衰减，则本指标主要发现的实际意义将大打折扣。一项受控人类研究（n ≥ 20 评估者，5 个模型，各 3 代生成）计划在 StabilityBench v2 中开展。

**闭源模型。** P3 分解需要模型内部。对于仅 API 可访问的模型，连接表层 β 与潜在约束动态的神经机制只能从开放权重验证中推断，无法直接验证。

**语言。** 仅英文。约束结构跨语言不同——语标书写系统、代词省略句法、敬语系统——β 可能随之变化。

**β_min。** 测量地板在 0.001 不是零。读数为 0.001 的模型不是"完美稳定"；它是"在当前提取器分辨率下未检测到衰减"。随着提取改进，地板可能下移，目前处在地板上的模型可能出现分化。

**已测试的基线。** 六个基线指标已与约束 β 进行了对比：字符级 Shannon 熵、type-token ratio（§3.5，表 3）、句子嵌入漂移（all-MiniLM-L6-v2 与 Gen0 的余弦相似度）、直接 LLM-judge 质量评分（GPT-4o-mini 按 1-10 分打分）、多 judge 纯约束提取（3 个评判模型直接对 5 个约束维度评分）以及延续困惑度（§3.5）。熵始终不变（所有模型 β_ent 均处于地板）。TTR 在递归下衰减但与 β 不相关（ρ = 0.000）。嵌入漂移是真实的但与 β 正交（ρ = 0.100，p = 0.873）。直接 LLM-judge 完全未检测到任何衰减（β_qual ≈ 0 对所有模型；Gen1 评分在所有情况下均高于 Gen0）。多 judge 纯约束提取尽管在 4/5 维度上具有可接受的评委间可靠性，但被 43–71% 的人类→AI 质量差距所主导，且无法在 AI 代际内检测到一致的递归退化——这确认了约束结构测量（而非质量感知）对于隔离递归信号的必要性。延续困惑度（GPT-4o-mini logprobs，15 个延续 token，n=10 个种子 × 9 个完整 4 代数据模型）产生可测量的 β_perp（0.015–0.105），但模型排名与 β_constraint 显著不同（Spearman ρ = 0.47，n=9）：DeepSeek-V3 按约束 β 是最好的模型（0.028），按困惑度 β 却是第二差（0.102）；而 GPT-4o 按约束 β 处于中等（0.099），按困惑度 β 却是最好的（0.015）。中等相关性由 Claude 家族模型驱动，其两个指标部分一致；非 Claude 模型显示接近零或反向的一致性。人类评估仍是重要的未来对比方向。现有结果已确立：β 捕捉到了熵、词汇多样性、嵌入相似度、任何形式的 LLM-judge 质量评分以及基于困惑度的文本自然度中均不存在的信息。

**general 维度。** general 维度被描述为多约束平衡的复合指标，但在表 2 中，它有时超过其组成维度（Llama 3.1 8B：general β = 0.261 对比 creative_writing β = 0.241）。复合指标如何能超过其所有组成成分尚未得到充分刻画，可能表明 general 捕捉了五个具名维度所未覆盖的方差。

**指令遵循。** 在递归下，模型可能偏离原始提示的主题或格式——这是一种与约束衰减不同的失效模式。为检验约束 β 是否仅仅在测量指令遵循衰减，一项对照实验跨 3 个模型 × 4 个能力 × 5 个种子 × 4 个递归代（共 240 次 API 调用）追踪了主题保真度（TF-IDF 余弦相似度对 Gen0 种子）、格式保真度（基于正则表达式的 rubric 二元检查各能力）及其几何平均 I_k（复合指令遵循得分）。对 I_k 拟合指数 β。

三个模型显示出显著解耦（表 4）：GPT-5.5——约束 β 最好的模型（0.011）——在指令遵循上灾难性崩溃（β_instr = 0.676，R² = 0.940，I_k：1.00→0.20→0.08→0.05）。GPT-4o-mini——中等约束 β（0.088）——在两项指标上以几乎相同的速率衰减（β_instr = 0.088，比值 = 0.99×）。Claude Opus 4.7——约束 β 最差的模型（0.164）——显示中等的指令遵循衰减（β_instr = 0.219，比值 = 1.3×）。跨三个模型，β_constraint 与 β_instr 呈负相关（Spearman ρ = −0.50）：约束稳定性最好的模型具有最差的指令遵循稳定性，反之亦然。

| 模型 | β_constraint | β_instr | 比值 | I_k Gen0→Gen3 |
|-------|:--:|:--:|:--:|:--:|
| GPT-5.5 | 0.011 | 0.676 | 62.2× | 1.00 → 0.05 |
| GPT-4o-mini | 0.088 | 0.088 | 0.99× | 1.00 → 0.26 |
| Claude Opus 4.7 | 0.164 | 0.219 | 1.34× | 1.00 → 0.11 |

三个模型均显示主题衰减快于格式衰减（所有情况下 β_topic > β_format），且 β_format 对 GPT-4o-mini 和 Claude Opus 4.7 拟合失败（格式保真度较高且非单调：两者 Gen3 的 F_k ≥ 0.60）。

这一解耦是迄今最强有力的证据，表明约束 β 测量的是一个与简单指令遵循衰减截然不同的现象。GPT-5.5 产出结构稳定但主题偏离的文本；Claude Opus 4.7 更紧扣主题而约束结构在显著衰退。两个指标捕捉了递归生成退化的正交维度，单独任一都不足以刻画模型的递归行为。

**递归 vs. 单次生成长度。** 观测到的部分退化可能仅是生成 token 总量的函数，而非递归本身。将递归 3 × 512 tokens 与来自同一种子的单次 1,536 token 生成进行对照，可以将递归机制与长度效应隔离开来。

## 6. 结论

RSI 测量的是标准评测工具箱所不测量的东西：当模型的输出成为它自己的输入——反复——会发生什么。在五大模型家族的 16 个模型中，这个"什么"的跨度达 15 倍——从近乎完美稳定到快速退化（β = 0.0109 到 0.1635）。

近乎普遍的 creative_writing 瓶颈不是偶然。它从约束层级中自然导出：E-II 型风格约束没有验证机制、没有锚定它的真值、没有纠正它的解析器。它们是约束结构中最柔软的点，而在递归下，最柔软的点最先断裂。唯一的例外——Gemini 2.5 Flash——证明了瓶颈不是自然定律。它可以被工程化消除，尽管可能付出其他维度的代价。

指标本身站得住，但附有重要限定。前瞻性方法论锁定消除了虚高早期估计的后验偏误。重测在已测的一个模型上产生完全相同的 β。温度在已测的两个模型上不影响排名。六个基线——熵、TTR、嵌入漂移、直接 LLM-judge、多 judge 纯约束提取和延续困惑度——均无法检测到 β 所捕捉的退化（五项中 Spearman ρ ≤ 0.10；困惑度 ρ = 0.47，n=9，模型排名显著不同）。然而，排名对种子源分布敏感（AI 种子 ρ=0.80，人类种子 ρ=0.40–0.60）；提取器与独立参照仅达到中等一致性（平均 |r|=0.47），其中两个维度处于噪声水平；下游代码质量校准（v3，5 模型，35 题）未产生预测关系（r=−0.12，p=0.87）——约束 β 不预测功能性代码质量退化的速率，确认提取器改进必须先于下游验证。神经梯度与框架预测方向一致，但仅限于单个小型开源模型，且五个梯度分量中有两个为零。每模型约 $0.50 的成本，随新模型发布进行定期重测在经济上是微不足道的。

递归生成不再是一个偏门部署模式。它是模型如何被训练（合成数据）、如何被对齐（自博弈）、以及如何被部署（智能体循环）的核心方式。一旦下游预测效度确立，模型的评测卡片上应当包含描述它在自己实际会运行的那个体制下表现的数字。β，尚待进一步验证，是该数字的候选。

## 附录 A：约束残差框架参考

本附录为主体文本中使用的框架术语提供自包含的定义。完整理论处理见 Deng（2025）。

### A.1 约束层级（L0–L3）

文本生成被建模为在分层约束层级上的约束优化：

| 层级 | 名称 | 描述 | 示例 |
|:-----:|------|-------------|---------|
| L0 | 物理 | Token 级别的句法合格性 | 词性一致、解析有效性 |
| L1 | 逻辑 | 二元一致性约束 | 非矛盾："下雨了。阳光明媚。"→ 违反 |
| L2 | 形式 | 确定性验证程序 | 数学推导规则、代码类型检查、形式证明 |
| L3 | 元 | 跨层约束协调 | 在事实准确性与风格流畅性之间平衡 |

L0 和 L1 约束是二元的（通过/不通过）。L2 约束是形式闭合的——可通过解析器、类型系统或推导规则验证。L3 约束治理层间交互。

### A.2 执行者类型（E-I, E-II, E-III）

约束通过三类执行者传递，按验证机制区分：

| 类型 | 名称 | 验证方式 | 示例 |
|:----:|------|:------------:|----------|
| E-I | 形式性 | 确定性（解析器/定理证明器） | 代码编译、数学推导 |
| E-II | 分布性 | 无——仅统计分布 | 创意写作风格、叙事语声、意象 |
| E-III | 参照性 | 外部真值 | 事实准确性、实体保真度、时间一致性 |

creative_writing 是典型的 E-II 执行者：风格约束没有解析器、没有二元检查、没有外部参照。这一结构属性——而非任何模型特定的缺陷——解释了为何 E-II 约束在递归下率先退化。

### A.3 约束可见性（P1–P4）

总约束残差 Π = Σ|∇σ_i| 分解为四个可见性组分：

| 组分 | 名称 | 描述 |
|:---------:|------|-------------|
| P1 | 活跃 | 在输出文本中直接可见的约束（例如，可读到的事实错误） |
| P2 | 潜在 | 通过输出结构间接可测的约束——塑造生成但本身不构成违反 |
| P3 | 被抵消 | 活跃但相互抵消的约束对；对可观测输出贡献为零，在梯度中存在 |
| P4 | 涌现 | 在足够递归深度下由现有约束间交互产生的新约束 |

P3 组分是约束空间的"暗物质"——在输出中不可见，但在逐 token 梯度分解中可检测（§4）。

### A.4 吸引子坍缩

在递归下，原本分离的约束维度逐步融合——这一过程称为**吸引子坍缩**。随着生成推进，σ_style 与 σ_syntax 变得日益相关（§4.3），约束空间的有效维度降低，而编码在维度间分离中的信息随之丢失。吸引子坍缩是 RSI 所测量的表层 β 衰减背后的神经机制。

### A.5 核心符号

| 符号 | 含义 |
|:------:|---------|
| Π = Σ\|∇σ_i\| | 总约束残差 |
| σ_fact, σ_syntax, σ_style, σ_safety, σ_coherence | 五个逐 token 梯度组分 |
| β | 递归稳定性指数：Π 跨代指数衰减速率 |
| C_k | 第 k 代总约束量 |
| λ_C | 被抵消约束占比的跨代增长率 |

## 附录 B：约束提取器

### B.1 架构

混合约束提取器结合基于规则的特征提取与 LLM-judge 增强：

- **基于规则的特征**（快速、确定性）：代码语法解析、数学运算符检测、实体提及提取、通过关键词模式的自相矛盾标记
- **LLM-judge 增强**（语义判断）：创意写作质量评分、细腻的逻辑一致性评估

混合设计的验证在三个层面进行：

| 验证层级 | 指标 | 结果 |
|---------|------|------|
| 特征级（3/8 特征） | Spearman ρ vs. LLM-judge 标注 | ρ = 0.93（E-I 逻辑密度），0.98（E-II 双词重复），0.92（E-III 专名大小写比） |
| ConstraintState 级（5 维） | 平均 \|Pearson r\| vs. 嵌入提取器 | \|r\| = 0.47（范围：0.15–0.90） |
| 能力级（6 维） | Spearman ρ vs. LLM-judge 质量偏好 | 总体 ρ = 0.81 |

在 ConstraintState 层面，一致性为中等（平均 \|r\| = 0.47，n = 152），此相关性足以支持比较性模型排名，但不足以支撑精确的逐样本约束违反分数。各维度一致性差异显著：sigma_fact（r = 0.90）和 sigma_syntax（r = 0.59）显示合理对齐，而 sigma_safety（r = 0.15）和 sigma_coherence（r = 0.17）接近噪声水平。改善 sigma_safety 和 sigma_coherence 的一致性为 StabilityBench v2 的提取器开发优先事项。

### B.2 各维度评分

| 维度 | 提取方法 |
|-----------|-------------------|
| creative_writing | LLM-judge：叙事结构、语声一致性、意象连贯性 |
| math_reasoning | 基于规则：数值运算有效性、推导步骤正确性 |
| code_generation | 基于规则：解析有效性（AST 提取）、功能模式匹配 |
| logical_consistency | 混合：自相矛盾检测（规则）+ 推理有效性（LLM） |
| factual_knowledge | 基于规则：实体共指消解、时间一致性检查 |
| general | 复合：多维约束平衡的加权平均 |

### B.3 提取示例

对于 creative_writing 维度的种子提示（"请写一篇关于灯塔看守人的短篇故事……"），典型第 1 代输出及其提取分数：

```
输出（节选）："灯塔看守人守望大海已经四十年。
  他熟悉每一朵浪花的声音，熟稔每一场暴风雨的气息……"

分数：
  creative_writing:  0.72  （叙事语声强烈，意象连贯）
  logical_consistency: 0.98 （未检测到矛盾）
  factual_knowledge:   1.00 （无可验证的事实主张）
  math_reasoning:      N/A  （无数学内容）
  code_generation:     N/A  （无代码内容）
  general:             0.85 （多约束剖面平衡）
```

约束残差 Σ|∇σ_i| 是所有评分维度的聚合违反梯度。β 则对该聚合量跨代的衰减进行拟合。

### B.4 基线对比

在方法开发期间，曾比较三种测量目标：total_constraint（Σ|∇σ_i|）、Shannon 熵和词汇多样性（type-token ratio）。total_constraint 被选为前瞻性锁定的目标，因为它是约束残差框架中理论驱动的核心量。§2.2 中的后验选择分析量化了逐模型目标选择将导致的偏误。§3.5（表 3）提供了在 16 个模型上与 Shannon 熵和 TTR 的直接 head-to-head 对比：熵对递归生成完全不变，TTR 排名与约束 β 不相关（Spearman ρ = 0.000）。

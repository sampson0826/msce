# DecayMonitor — LLM 递归稳定性评测平台框架

**2026-05-12 | 方向确认版**

---

## 一、一句话定位

**在 LLM 评测矩阵中新增"递归稳定性 β"这个维度。** 现有评测全部测单次质量，我们测模型在自主循环中能撑多久。

---

## 二、β 是什么

模型递归读取自己输出时，每代丢失的约束质量比例。

```
math_reasoning: Gen0: 1.000 → Gen1: 0.782 → Gen2: 0.521 → Gen3: 0.338
                                    ↓ β=0.31/代
```

| β 值 | 含义 | 10 代后质量 | 适用场景 |
|------|------|:----:|------|
| < 0.15 | 极稳定 | ~20% | 长链 agent |
| 0.15-0.25 | 较稳定 | ~5-10% | 中等 agent |
| 0.25-0.35 | 退化明显 | ~2-5% | 短链任务 |
| > 0.35 | 快速退化 | < 1% | 不宜 agent |

6 个能力维度独立测 β：数学推理、代码生成、事实知识、逻辑一致、创意写作、通用能力。

## 五、算法原理（三步）

### 第 1 步：文本 → 8 特征（纯规则，CPU only）

```
输入文本
    │
    ├─ E-I（逻辑层）
    │   ├─ ei_logic_density    逻辑连接词/总token
    │   └─ ei_syntax_cv         句子长度变异系数
    │
    ├─ E-II（风格层）
    │   ├─ eii_bigram_repetition 重复bigram/总bigram
    │   ├─ eii_unique_word_ratio  唯一词/总词
    │   ├─ eii_filler_ratio       填充词占比
    │   └─ eii_truncation_ratio   截断长词比例
    │
    └─ E-III（边界层）
        ├─ eiii_proper_case_ratio  首字母大写率
        └─ eiii_number_integrity   数字保真率
```

### 第 2 步：8 特征 → S_n（约束质量分）

```
sigma_syntax  = 0.65×逻辑密度 + 0.35×句法CV
sigma_style   = 词汇多样性×(1-0.5×重复-0.3×截断-0.2×填充)
sigma_fact    = 0.55×大小写规约 + 0.45×数字完整性
sigma_coherence = 0.55×逻辑密度 + 0.45×(1-重复)
sigma_safety  = 0.5

S_n = Σ5σ / 5     ∈ [0,1]
```

### 第 3 步：S_n 序列 → β

```
S_n = S_0 × (1-β)^n
log(S_n/S_0) = n × log(1-β)

最小二乘线性回归 → 斜率 → β = 1 - e^斜率
6个能力维度各算一个 β → 全局 β = 各维度 β 均值
```

**验证：** 纯文本特征 vs LLM judge（Claude）Spearman 相关性：E-I 0.93 / E-II 0.98 / E-III 0.27。E-III 较弱但权重已降低。

## 六、技术架构

```
decaymonitor.ai
    │
    ├─ 前端 (React)
    │   ├─ 排行榜首页
    │   ├─ 模型详情页（6维衰减曲线）
    │   └─ 模型对比页
    │
    ├─ 后端 (FastAPI)
    │   ├─ GET  /leaderboard
    │   ├─ GET  /model/{id}
    │   ├─ POST /eval          → 异步评测任务
    │   └─ POST /compare
    │
    ├─ 评测引擎 (ExperimentRunner)
    │   ├─ ProviderAdapter → API 调用
    │   ├─ DecayEngine     → β 拟合
    │   └─ ExecutorClassifier → 退化诊断
    │
    ├─ 任务队列 (Celery + Redis)
    │   └─ 每周一自动评测 所有模型
    │
    └─ 数据层 (PostgreSQL + S3)
        ├─ β 历史数据库
        ├─ JSONL 归档
        └─ 实验元数据（API成本/时间）
```

**单模型评测耗时：** 12 seeds × 3 gens × 0.5s sleep + API 延迟 ≈ 2 分钟。**成本：** ~$0.50/模型（API 调用费）。
